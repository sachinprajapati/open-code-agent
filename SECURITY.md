# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature for this repository when it is available. Include a clear description, affected versions or commits, reproduction steps, impact, and any suggested mitigation.

We will review reports in good faith, work to validate them, and coordinate a fix and disclosure timeline with the reporter where appropriate.

## Scope

This foundation release does not execute model-generated commands or connect to model providers. Future security-sensitive capabilities will be documented as they are introduced.
